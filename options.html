Connect Sara
to your computer.

Set up the optional Windows companion to let Sara open a few approved apps and use helpful shortcuts. Browser controls work without it.

01

Install the Windows companion

Keep this project folder on your computer. In its folder, open PowerShell and run powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_windows.ps1. Enter the Extension ID shown below. This bypass applies only to setup and does not change your PowerShell policy or install a background service.

02

Add your local access token

Copy the token shown by setup and save it here. Sara checks the local companion from this page first. If Chrome asks to allow Sara to connect to your computer or local network, choose Allow. The token stays in this Chrome extension on this computer.

VOICE

Language & spoken replies

Choose the language Sara listens for. Tap the microphone once to start a visible voice session; say “stop listening” to pause it.

PRIVACY & CONTROL

What Sara can do

  • Manage normal Chrome tabs across windows and open approved websites.
  • With the Windows companion running: launch Start Menu apps by name, open user folders, search supported document/media files, and switch or manage app windows.
  • Inspect accessible UI controls; Sara asks before activating a named control. It asks before locking Windows or closing a tab.
  • Never run free-form commands, open arbitrary executable paths, read passwords, submit web forms, or listen in the background.

Sara does not save audio or transcripts. Chrome's speech recognition may use a server service, and may not work offline. Check Chrome's speech settings before speaking sensitive information.

To turn off desktop access, clear the token here and close the companion window.
