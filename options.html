Connect Sara
to your computer.

Set up the optional Windows companion to let Sara open a few approved apps and use helpful shortcuts. Browser controls work without it.

01

Install the Windows companion

Keep this project folder on your computer, then right-click setup_windows.ps1 and choose Run with PowerShell. Enter the Extension ID shown below. The script creates a local access token; it does not install a background service.

02

Add your local access token

Copy the token shown by setup and save it here. It stays in this Chrome extension on this computer.

Not connected
VOICE

Language & spoken replies

Choose the language Sara listens for. Tap the microphone once to start a visible voice session; say “stop listening” to pause it.

PRIVACY & CONTROL

What Sara can do

  • Manage Chrome tabs and open a fixed list of websites.
  • With the Windows companion running: open Notepad, Calculator, and File Explorer; switch windows; show desktop; change volume; launch Task Manager or screenshot capture.
  • Ask for your confirmation before locking Windows or closing a tab.
  • Never run free-form commands, read passwords, submit web forms, or listen in the background.

Sara does not save audio or transcripts. Chrome's speech recognition may use a server service, and may not work offline. Check Chrome's speech settings before speaking sensitive information.

To turn off desktop access, clear the token here and close the companion window.
