# JARVIS OS System Overview

JARVIS OS is a modular AI operating system that coordinates specialized agents, memory, events, approved integrations, and a command-center interface.

## Goals
- One orchestration layer for business and personal workflows
- Specialized agents with explicit responsibilities
- Provider-agnostic AI model access
- Durable task state and auditable execution
- Human approval for consequential external actions

## Major layers
1. Command Center
2. API and orchestration
3. Agent runtime
4. Memory and retrieval
5. Event and worker infrastructure
6. Integrations
7. AWS infrastructure

The existing Chrome/Windows assistant remains an isolated local capability behind validated action contracts.
